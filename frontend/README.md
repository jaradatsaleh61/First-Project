# Expense Tracker

A full-stack web application for tracking personal expenses.

The application allows users to add, view, edit, delete, and filter expenses. It also displays the total amount, number of expenses, and highest expense.

The frontend communicates with a Node.js and Express backend through a REST API, and the backend stores the data in PostgreSQL.

## Features

- Add a new expense
- View all expenses
- Edit an existing expense
- Delete an expense
- Filter expenses by category
- View all expenses using the "All" filter
- Display total amount of expenses
- Display number of expenses
- Display highest expense
- Validate expense amounts
- Bootstrap loading spinner
- Bootstrap error alerts
- Display backend error messages
- Responsive design for desktop and mobile
